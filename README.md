# Session 即時溝通

這是一個放在你電腦上的小網頁，用動畫即時呈現多個 Claude Code session 現在正在怎麼互傳訊息。

## 怎麼開

```
cd /Users/weihung/Desktop/work/session-communicate
npm start
```

然後用瀏覽器打開 http://127.0.0.1:4567 。

想換別的埠號就這樣開：`PORT=5000 npm start`。

## 你會看到什麼

背景是慢慢漂的星塵和呼吸般的極光色團。每個還在線的 session 是一顆發光的球，名字寫在球裡，排成一圈。新開的 session 會彈出來，關掉的會縮小消失。球外面的光環綠色表示「閒置」，橘色在跳、有一圈旋轉的虛線環和三顆小光點繞行表示「工作中」。

有人傳訊息時，一顆彗星會從寄件方飛到收件方，拖著尾巴和一點火花。到達時收件方亮一下、爆出粒子和兩圈衝擊波。兩顆球之間的線越粗，代表它們聊得越多。

- 三分鐘內有互傳的兩顆球之間，連線會發光。任一方還在工作中就標「正在溝通」，兩邊都閒置就標「剛聊過 · 幾分鐘前」。
- 系統設定「減少動態效果」時，星塵、粒子全部停掉，只保留必要的訊息飛行。
- 收件方若正在忙，底下會標「處理剛收到的訊息」。
- 滑鼠移到任何一顆球上會跳出小卡片，寫它正在做什麼：正在跑的動作、剛剛說的話、最近收到的指示、工作目錄，每 3 秒自動更新。滑鼠移開就收起，移到卡片上會留著。
- 訊息內容不在這裡看，回終端看就好。

## 資料從哪裡來

它不會攔截任何東西，只是讀 Claude Code 自己留在 `~/.claude/projects/` 裡的對話紀錄。
寄出的那方紀錄裡有 SendMessage 呼叫，收到的那方紀錄裡有 cross-session-message 標籤，程式把兩邊對起來就變成一則訊息。
在線名單讀的是 `~/.claude/sessions/`。

它只讀不寫，關掉網頁對 Claude 沒有任何影響。
